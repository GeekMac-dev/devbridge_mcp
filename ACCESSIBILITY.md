# Accessibility

DevBridge MCP primarily exposes MCP tools and a local development activity viewer, rather than a public-facing website.

We aim to keep documentation navigable with descriptive headings and links, readable markdown, and clear instructions. When changes affect the activity viewer, browser utilities, or other visual interfaces, please consider keyboard operation, screen-reader labels, focus visibility, contrast, and readable error states.

No formal accessibility conformance claim or independent WCAG audit is currently available.

To report an accessibility issue, use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.yml), select the relevant feature, and describe the barrier and preferred improvement. Do not include private screenshots or sensitive data.
