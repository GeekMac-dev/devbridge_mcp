# Code of Conduct

## Our commitment

DevBridge MCP welcomes developers of different backgrounds and experience levels. We aim to keep discussions and collaboration respectful, inclusive, and technically constructive.

## Expected behavior

- Be courteous and patient when reviewing ideas, issues, and pull requests.
- Offer actionable technical feedback; critique code, not people.
- Respect differing experience levels and perspectives.
- Respect others' privacy, credentials, and intellectual property.
- Use appropriate language in project spaces.

## Unacceptable behavior

Harassment, hate speech, discriminatory insults, threats, intimidation, personal attacks, doxxing, sexualized harassment, or deliberately sharing another person's private information are not acceptable.

Do not post passwords, API keys, user data, secrets, or working exploit details in public issues or pull requests.

## Scope and moderation

This policy applies to the project's issues, discussions, pull requests, and other official collaboration spaces. Maintainers may edit, hide, lock, or remove abusive material, request changes in behavior, or restrict participation as appropriate to protect the community.

Report non-security conduct concerns by opening a GitHub issue with only non-sensitive information and asking the maintainer for a private contact channel. If a report involves a security vulnerability, use [SECURITY.md](SECURITY.md) instead. Do not post personal or confidential evidence publicly.
