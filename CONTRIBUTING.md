# Contributing to DevBridge MCP

Thanks for your interest in improving DevBridge MCP, originally created by
[GeekMac-dev](https://github.com/GeekMac-dev).

## How to contribute

1. Open an issue describing the bug, improvement, or proposed feature.
2. Fork the repository, make a focused branch, and keep changes limited in scope.
3. Test changes with `npm run build`, `npm run test:integrations`, and
   `npm run test:design`.
4. Submit a pull request explaining what changed, why, and how it was tested.

Do not include real credentials, private configuration, user histories, local
browser profiles, company data, or files that you do not have permission to
redistribute.

## Code of conduct

Be respectful, specific, and constructive when discussing changes. Report
security issues privately to the maintainer rather than posting credentials,
sensitive data, or exploit details in a public issue.
